# 子智能体拆分协议（跨平台）

> 2026-10-19 立。目标：**不依赖任何平台的子代理 API**，让任何 agent 平台都能准确拆分 12 个角色。

## 0. 一句话

**子智能体 = 同一模型的另一个上下文窗口。** 独立性来自「彼此看不到对方写了什么」，
不来自模型不同，也不来自平台是否提供 Task/Agent 工具。

所以本项目把隔离做在**文件层**：每个角色只给一份白名单 + 一份禁读清单，
产物写到固定路径。平台只要会「读文件、写文件」，就能跑。

## 1. 平台兼容性

| 平台能力 | 怎么跑 | 是否等价 |
|---|---|---|
| 有子代理/任务工具（Task、Agent、subagent 等） | 用 `_role_prompt.py` 生成提示词，作为子代理的 prompt | ✅ 完全等价 |
| 只能开新会话/新窗口 | 生成提示词 → 新会话粘贴 → 让它写文件 | ✅ 完全等价（推荐） |
| 只有一个对话框、不能开新会话 | 一次只跑一个角色，跑完清空上下文再跑下一个 | ⚠️ 次优：靠人工保证不串味 |
| 不能读写本地文件 | **不能跑**（本项目以文件为唯一事实源） | ❌ |

**结论**：只要平台能读写本地文件，就能准确拆分；不能开新会话的平台只能降级为「人工串行」。

## 2. 三步跑一个角色

```bash
# 1) 生成该角色的完整提示词（含白名单/禁读/契约/篇幅/自验）
./.venv/Scripts/python.exe wb_analysis/_role_prompt.py 0700.HK 2026-10-16 bear --out /tmp/bear_prompt.md

# 2) 在新会话里贴入 /tmp/bear_prompt.md 的全部内容（不要带任何历史消息）

# 3) 回到主会话校验
./.venv/Scripts/python.exe wb_analysis/_lint_drafts.py wb_analysis/drafts/0700.HK_2026-10-16 \
    wb_analysis/evidence/0700.HK_2026-10-16.md wb_analysis/evidence/0700.HK_2026-10-16.supplement.md
```

提示词里已经写死：可读文件绝对路径、禁读文件（牛派禁读熊稿，反之亦然）、
评级词白名单、绝对价格要求、4,000–4,800 字符、每句须承载信息、落盘路径、长度自验命令。

## 3. 编排（R1 → R2 → R3）

| 轮次 | 谁 | 输入 | 产出 |
|---|---|---|---|
| R1-a | 子会话 A | 白名单（证据 + 简报 + 派生 + FRAMEWORK） | `2_research/bull.md` |
| R1-b | 子会话 B | **与 A 完全相同**的白名单 | `2_research/bear.md` |
| R2 | 主会话（研究经理） | A、B 两稿 + 证据 | `2_research/manager.md` |
| R3 | 主会话（交易员/风控/组合经理） | 全部前置稿 | 其余 4 份 |

**R1 必须并行/互不可见**：两个提示词里都**不出现对方的存在**，否则会「预判对方」而趋同。

## 4. 拆分是否真的成功（可判定）

R2 时必须回答两个问题：

1. 两稿在**哪些事实上一致**？（应高度一致 —— 同一份证据）
2. 两稿在**哪些解释上分歧**？（应有实质分歧 —— 否则就是同质化）

**失败判据**：两稿引用的证据集合重合率 **>70%** ⇒ 判本轮拆分失败，重跑 R1（换提示词措辞或换会话）。

> 实测基线（2026-10-19 之前的单上下文写法）：牛熊两稿引用同一批数字（PE/ROE/资金各一条），
> 重合率接近 100%，「逐条反驳」实际是自问自答 —— 这正是本协议要解决的问题。

## 5. 质量闸门（每个角色都要过）

| 检查 | 工具 | 判据 |
|---|---|---|
| 评级词/结论块 | `_verify_ratings.py` | 六席各 1 处；分析师与牛熊 0 处 |
| 篇幅与信息密度 | `_lint_drafts.py` 5 / 4d | 4,000–4,800（硬下限 4,000，>6,000 判偏长）；无重复句 |
| 算式自洽 | `_lint_drafts.py` 4b | `a op b = c` 可复算 |
| 跨轮引用 | `_lint_drafts.py` 4c | 出现「上轮/此前报告」即告警 |
| 数字溯源 | `_lint_drafts.py` 1 | 未溯源数字逐个人工判断 |

## 6. 禁止事项

1. **不得**把两个角色放在同一个会话里写（上下文会互相污染）。
2. **不得**在提示词里贴对方稿件（包括「供参考」）。
3. **不得**让子智能体修改证据包、简报或 `meta.json` —— 产物只有自己那一份 md。
4. **不得**用「上一轮的结论」当输入（铁律 55）。
5. 平台没有文件读写能力时，**不要**退化成「让模型背数据」，直接换平台。
